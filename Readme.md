# Healthcare Readmission Analysis

## 1. Data Understanding

### Problem Statement
A healthcare provider wants to understand which patient, clinical, and healthcare-utilization factors are associated with 30-day hospital readmissions and identify patient groups with higher readmission rates.

### Objective
The objective of this project is to analyze hospital encounter data, identify factors associated with 30-day readmissions, and translate the findings into actionable healthcare insights.

### Dataset
The dataset contains hospital encounter records from 130 U.S. hospitals and integrated delivery networks covering the years 1999–2008.
